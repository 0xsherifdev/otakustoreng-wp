OTAKU STORE NG — CUSTOM SHIPPING ZONES (Client-handled NG + Ghana)
===================================================================
Goal: Client handles delivery for Lagos LGAs, all Nigerian states, FCT, and Ghana
with their OWN flat rates. Terminal Africa is used ONLY for the rest of the world.
Where: WordPress Admin > WooCommerce > Settings > Shipping > Shipping zones.
All amounts in NGN. Prices = NGN base currency.

WHY LAGOS IS DIFFERENT
----------------------
WooCommerce matches addresses by country > state > postcode. It has all NG states
+ FCT built in (interstate + Ghana are easy). But "Lagos" is ONE state — WooCommerce
has no LGA concept, so you cannot auto-detect a customer's LGA.
SOLUTION: create ONE "Lagos" zone and add 20 flat-rate methods (one per LGA). The
Lagos customer sees a selectable list and picks their LGA. 100% native, no plugin.

ZONE ORDER (IMPORTANT)
----------------------
WooCommerce uses the FIRST zone (top→bottom) whose region matches. Arrange exactly:
 1. Lagos
 2. Nigeria - N7,000 states
 3. Nigeria - N8,500 states
 4. Nigeria - N6,000 states
 5. Nigeria - N5,500 states
 6. Ghana
 7. (bottom) "Locations not covered by your other zones" = Terminal Africa
Drag zones to reorder via the handles on the Shipping zones list.

TERMINAL AFRICA RESTRICTION
---------------------------
Add the Terminal Africa shipping method ONLY to zone 7 (Rest of World).
Do NOT add it to zones 1-6, so NG/Ghana show only your flat rates.
* VERIFY at checkout: enter a Lagos address — you should see ONLY the 20 LGA options,
  not Terminal courier rates. If Terminal still appears for NG, check the Terminal
  plugin settings for a per-zone/destination toggle or contact Terminal support.

===================================================================
HOW-TO (clicks)
===================================================================
1. WooCommerce > Settings > Shipping > Shipping zones > "Add zone".
2. Zone name (e.g. "Lagos"), then in "Zone regions" type the state(s) and select
   the "Nigeria — <State>" entries. For Ghana pick the country "Ghana".
3. Click "Add shipping method" > "Flat rate" > save > then "Edit" the method to set
   Title and Cost. Repeat to add more methods to the same zone (Lagos = 20 methods).
4. Drag zones into the order listed above. Terminal stays in the bottom catch-all zone.
5. Test: go to checkout, change the shipping State to Lagos / Abia / Oyo / Ghana / USA
   and confirm the correct fee(s) show and Terminal only appears for "rest of world".


===================================================================
DECISIONS / NOTES FOR CLIENT
===================================================================
* PRODUCT WEIGHTS: Ghana tiers (and any future weight rules) need real product
  weights. Set weight on each product/variation; otherwise WooCommerce uses the
  default and may mis-tier. (Same point as Terminal's default-weight setting.)
* FREE SHIPPING: REMOVED (client decision). The N100,000 free-shipping promise is
  dropped — flat rates always apply on every NG zone. Do NOT add a "Free shipping"
  method to any zone. Also remove the "Free Shipping" service badge/copy from the
  homepage + footer + any "Flexible Payment/Free Shipping" service row so the site no
  longer advertises free shipping (it would contradict the flat rates at checkout).
* LAGOS LGA — STRICTER ALTERNATIVE: the 20-method list relies on honest self-select.
  For a locked LGA dropdown tied to the address (cannot pick a cheaper LGA), you need
  a custom checkout field + fee snippet or a paid table-rate plugin. The native
  multi-method approach above is the no-code, client-maintainable default.
* CURRENCY: fees are NGN; with Curcy showing other currencies, the flat rate converts
  to the customer's display currency but charges in NGN via Paystack (as configured).
