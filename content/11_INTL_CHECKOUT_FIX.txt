OTAKU STORE NG — FINAL FIX: international checkout "Please fill in all required fields"
=======================================================================================
This REPLACES the approach in 09_CHECKOUT_STATE_FIX.txt (that one didn't work — see why
below). Deactivate the "Fix: International State not required (except NG)" snippet, and
deactivate the "TEMP diagnostic: error trace" snippet. Add this one instead.


ROOT CAUSE (confirmed via logs)
-------------------------------
1) For an international address (e.g. Kenya), the Terminal Africa plugin OWNS the State
   field and never fills WooCommerce's native billing_state -> it stays empty.
2) State is treated as REQUIRED for such countries -> a required-field error is raised.
3) The MINIMOG THEME consolidates that into one generic error:
      Minimog\Woo\Checkout->update_error_messages
      @ themes/minimog/framework/woocommerce/checkout.php:184
      code:  some_required_fields
      text:  "Please fill in all required fields."
   (This is why changing WooCommerce's field "required" flags had no effect — Minimog
   validates independently of the field config.)

Nigeria/Ghana are unaffected: Nigeria fills a real State (needed by the shipping zones);
Ghana doesn't enforce a required State.


THE FIX
-------
Clear that generic error AFTER Minimog adds it (priority 11 > Minimog's 10), but ONLY:
  - for NON-Nigeria orders, and
  - when every genuinely required field IS filled (so real mistakes are still caught).
Terminal keeps the true destination in its own fields, so an empty native State is fine.


HOW TO INSTALL
--------------
1. WPCode: DEACTIVATE "Fix: International State not required (except NG)" (from file 09).
2. WPCode: DEACTIVATE "TEMP diagnostic: error trace" (from file 10).
3. WPCode > Add Snippet > PHP Snippet. Title: "Fix: International checkout (Minimog + Terminal)".
4. Paste everything below ===PHP START===. Insertion: Auto Insert > Run Everywhere. Activate.
5. Hard-refresh checkout and test (see TEST).


===PHP START===
// --- Otaku Store NG: unblock international checkout ---
// Terminal owns the State field for international addresses and leaves WooCommerce's
// native billing_state empty; Minimog then shows a generic "Please fill in all required
// fields" (code: some_required_fields). Clear that error for NON-Nigeria orders, but
// only when every other required field is actually filled, so genuine mistakes are still
// caught and Nigeria (which needs State for its shipping zones) is never touched.
add_action('woocommerce_after_checkout_validation', function ($data, $errors) {
    if (!is_wp_error($errors)) {
        return;
    }
    $country = isset($data['billing_country']) ? $data['billing_country'] : '';
    if ($country === '' || $country === 'NG') {
        return; // keep State strictly required for Nigeria
    }
    if (!in_array('some_required_fields', $errors->get_error_codes(), true)) {
        return; // a different/real validation problem — leave it alone
    }

    // Billing: every required field EXCEPT State must be present.
    $billing = array(
        'billing_first_name', 'billing_last_name', 'billing_email', 'billing_phone',
        'billing_address_1', 'billing_city', 'billing_postcode',
    );
    foreach ($billing as $key) {
        if (empty($data[$key])) {
            return; // a real field is missing — keep the error
        }
    }

    // If shipping to a different address, its core fields (except State) must be filled too.
    if (!empty($data['ship_to_different_address'])) {
        $shipping = array(
            'shipping_first_name', 'shipping_last_name',
            'shipping_address_1', 'shipping_city', 'shipping_postcode',
        );
        foreach ($shipping as $key) {
            if (empty($data[$key])) {
                return;
            }
        }
    }

    // Only the native State is missing — Terminal supplies the destination itself. Clear it.
    $errors->remove('some_required_fields');
}, 11, 2); // priority 11 = AFTER Minimog's consolidation (priority 10)
// --- end ---
